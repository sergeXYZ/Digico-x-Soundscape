Digico×Soundscape — Raspberry Pi (64-bit / aarch64)
===================================================

Voraussetzung:
  sudo apt install python3 python3-venv python3-pip

Schnellstart
------------
1. Zip entpacken
2. chmod +x install.sh Digico-x-Soundscape.sh
3. ./install.sh
4. ./Digico-x-Soundscape.sh
5. Browser: http://127.0.0.1:8765/

Optional Binary: ./build_binary.sh → dist/Digico-x-Soundscape

DiGiCo Pad → Bridge IP des Pi. DS100 Ports: 50010 / 50011.
