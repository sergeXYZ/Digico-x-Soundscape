Digico×Soundscape — Windows (portable)
======================================

Kein System-Python nötig.

Status: In this release Windows packages are UNTESTED on real hardware.

Schnellstart
------------
1. Zip entpacken
2. Doppelklick: start_bridge.bat
   (Erststart richtet portable Python ein — ca. 1 Minute)
3. System-Browser öffnet http://127.0.0.1:8765/
4. IPs / Ports / Mappings setzen → Start
5. Beenden: Konsolenfenster schließen

Optional EXE: build_exe.bat → dist\Digico-x-Soundscape.exe
  (auf dem Ziel-PC bauen; pywebview optional für eingebettetes Fenster)

DiGiCo Pad → Bridge IP dieses PCs. DS100 Ports: 50010 / 50011.
